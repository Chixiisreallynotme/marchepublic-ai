## Codebase Patterns

- Framework: Next.js 15 App Router + TypeScript (strict)
- Styling: Tailwind CSS with `cn()` helper from lib/utils.ts (clsx + tailwind-merge)
- Database: Prisma ORM over SQLite (`prisma/schema.prisma`, singleton client in lib/prisma.ts)
- Validation: Zod schemas colocated under lib/schemas/
- Testing: Vitest + @testing-library/react + jsdom, tests live in `__tests__/`
- Components: server components by default; client components only where interactivity requires ("use client")
- Naming: PascalCase components in components/, kebab-case routes in app/
