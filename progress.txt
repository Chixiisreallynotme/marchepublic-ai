## Codebase Patterns

- Framework: Next.js 15 App Router + TypeScript (strict), React 19
- Styling: Tailwind CSS with `cn()` helper (clsx + tailwind-merge); design tokens in globals.css + tailwind.config.ts
- Database: Prisma ORM over SQLite (`prisma/schema.prisma`, singleton in lib/prisma.ts); `npm run db:push` applies schema
- Validation: Zod schemas colocated under lib/schemas/; ActionResult<T> pattern { success, data | error, issues }
- Server Actions in lib/actions/*("use server"); REST routes under app/api/* for client fetch
- Testing: Vitest + @testing-library/react + jsdom in __tests__/; prisma mocked via vitest.setup.ts
- Mono-tenant V1: single organization via lib/org.ts getActiveOrganization()
- Sirene source: ETALAB recherche-entreprises.api.gouv.fr (no token); mock only with SIRENE_MOCK=1
- CERFA PDFs rendered server-side with pdf-lib at GET /api/cerfa/[id]/pdf
